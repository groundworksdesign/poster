# REQ-002: Layer import rule

## Requirement

`src/domain` and `src/application` do not import Remix, Electron, or Playwright.

## Acceptance (from epic Validation)

- [ ] No Remix / Electron / Playwright imports under `src/domain` or `src/application`.
- [ ] Any accidental coupling is removed or moved to an adapter/presentation layer.

## Current code pointers

- `src/application/SessionTransport.ts` — use-case/port; must stay framework-free
- Durable guard: `src/__tests__/layer-import-rule.test.js` (walks domain + application, including colocated tests; fails on forbidden package/relative imports)
