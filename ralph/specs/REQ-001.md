# REQ-001: E2E path roots

## Requirement

Every `tests/e2e` helper/spec that needs the repository root or `public/` resolves them correctly after the `e2e/` → `tests/e2e` move (not `tests/` as root).

## Acceptance (from epic Validation)

- [ ] `electronHelpers` launches Electron with the directory that contains `package.json` and `src/adapters/electron/main.cjs`.
- [ ] Electron theme relaunch uses the same correct repo root.
- [ ] Sample-deck paths resolve to existing `public/sample-slide-deck.json`.
- [ ] No `tests/e2e` file still treats `path.join(__dirname, '..')` as the repository root when it needs the real root.

## Current code pointers

- `tests/e2e/electronHelpers.ts`: `root = path.resolve(__dirname, '..')` (wrong after move)
- `tests/e2e/electron-theme-relaunch.spec.ts`: same one-level-up root
- `tests/e2e/home-library.spec.ts`, `tests/e2e/library.spec.ts`: `join(__dirname, '..', 'public', ...)`
- Good reference: `tests/e2e/playwright.remix.config.ts` uses `join(__dirname, '..', '..')`

## Test plan

- Assert resolved paths exist (`package.json`, `src/adapters/electron/main.cjs`, `public/sample-slide-deck.json`).
- Prefer running affected Electron / Remix specs when the environment allows.
