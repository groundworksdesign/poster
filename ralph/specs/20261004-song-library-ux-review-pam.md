# Poster song library: UX review by Pam (2026-10-04)
Review of brief v1.1. Design only.

## Screens and flows
- Add song slide: a chooser with Pick from library (default) and Import a file. If the library is empty, it says so and points to Import or Add by hand.
- Library picker: one search box for title, book, or number, plus an optional book filter. Each row shows title, book, and number. Rows that share a title show the first verse line inline. Enter or double-click adds the song after the current slide.
- Import: one review screen per file. It shows a checklist of songs, all checked by default. Songs with no lyrics are grouped with one choice for the group. Title matches expand to show number and lyrics side by side, and keep both is the default. One Import button.
- Manage library: a library page with search, Add song, Edit, Delete, Import, and a used-in-N-decks count on each row.

## Keeping prompts light
- Fold the multi-song, no-lyrics, and title-match prompts into the single review screen.
- Show problem sections only when they apply.
- Save to library is a checkbox on the same screen.
- Ask about updating decks only when the song is used in a deck, and list those decks with checkboxes.
- A single clean song file skips the review screen.
