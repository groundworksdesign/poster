## Why it fails
1. **AC-009 / AC-014 (REQ-010/REQ-017): FAIL, on tip and packaged.** When you import a single clean song file in the panel, the song is saved to the library **as soon as you pick the file**. No "Also save to my library" box is shown, and no yes is asked for. The slide comes in linked. Cancel then leaves the library song behind: `{"boxBeforeFile":0,"boxAfterFile":0,"savedToLibraryBeforeSaveSlide":1,"libraryAfterCancel":1,"slidesAddedAfterCancel":0}`. The cause is in the code: `SongSlideEditPanel.handleImportFile` runs `savePayloads` whenever `!plan.needsReview`, and the box only renders inside the review. At 1d4b7b3 this box was visible before the file was picked.
2. **In-scope item "scratch save goes through review and then links": FAIL for existing scratch slides, on tip and packaged.** The setup is an existing scratch slide whose title is already in the library (or which has no words). If you tick Also save and press Save slide, the app shows "Slide saved" and closes the panel. The review never appears, and nothing is saved or linked. **The Words edits made in that session are silently thrown away:** `{"reviewShown":0,"panelOpen":0,"message":"Slide saved","slideLinked":false,"wordsEditKept":false,"libraryDelta":0}`. In the code, `commit` returns `null` after `setScratchPlan`, and `DeckBuilder.saveSlideEdits` (L363–393) ignores a null commit and still saves the old draft. A **new** scratch slide works correctly: review → keep both / replace / skip → linked.
3. **Roy decision 5 ("Cancel leaves nothing behind"): FAIL on the library side.** Slides pass: nothing joins the deck before Save slide. But library songs are written before Save slide in three places:
   - when the import review is confirmed (library 13→15 before Save slide);
   - when a single clean file is picked;
   - when the scratch review's "Save to library" is confirmed.

   Cancel after any of these leaves the songs in the library.

Everything else is green: regression, flake, CI, Present-unchanged, existing decks, theme, beta, DeckBuilder keys, and decisions 1, 2, 3, 4, 6 and 7.
