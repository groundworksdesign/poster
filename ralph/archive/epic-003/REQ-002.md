# REQ-002 — Stronger setSimpleFullScreen fallback

## Statement

If the system menu bar still shows after native fullscreen (or native FS cannot be used), apply `setSimpleFullScreen` while preserving easy exit.

## Acceptance

- [ ] Menu-bar-still-visible heuristic (darwin) → simple fullscreen
