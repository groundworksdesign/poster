# REQ-002: Showing row highlight

## Requirement

The currently playing slide in the list has a distinct Showing background.

## Acceptance (from epic Validation)

- [ ] Live slide row has a distinct **Showing** background (teal per planning mock).
- [ ] Only one row is marked Showing at a time.
- [ ] **Send**, **Start**, **Next**, **Previous**, and **Go** update which row is Showing.
- [ ] **End** blanks presentation and does not leave a stale Showing row.

## Current code pointers

- `src/Deck/DeckBuilder.tsx`: `presentSlideIndex`, `lastSentSlideId`, `presentationBlank`
- `src/App.css`: `.deck-slide-item` (no showing variant yet)

## Test plan

- Unit test: after Start or Send, exactly one row has showing class/data attribute; after End, none.
