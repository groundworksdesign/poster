# REQ-001: Song advance after last lyric

## Requirement

After a song finishes, presentation advance goes to the next deck slide, not back to the start of that song.

## Acceptance (from epic Validation)

- [ ] Last lyric stage, then **Next** shows the following deck slide (not song restart).
- [ ] Last lyric stage, then **right-arrow** shows the following deck slide.
- [ ] Last lyric stage, then row **Advance** shows the following deck slide.
- [ ] Never restart that song when advancing past the final stage.
- [ ] Mid-song **Advance** still steps lyrics (staged pairs).

## Current code pointers

- `src/Deck/DeckBuilder.tsx`: `navigatePresentationNext`, `handleSongStageAdvance` (`(last + 1) % total` wrap bug)
- `src/utils/stagedSongSlide.ts`: `getSongStageCount`, `buildStagedSongSlide`

## Test plan

- Unit test in `DeckBuilder.unit.test.tsx`: deck with song slide then general slide; advance through all song stages; assert next `postMessage` is the general slide, not stage 0 of the song.
